# De Jongh Allroundservice — LJ Studio Essentieel demo

## Mapstructuur voor GitHub
Alle losse websitebestanden staan in de hoofdmap. **Alleen `assets/` is een submap**. Upload de volledige inhoud van deze map naar de root van een GitHub-repository.

## Demo bekijken
Open `index.html` lokaal, of activeer GitHub Pages via Settings → Pages → Deploy from branch → main → /(root).

## Voor publicatie verplicht
- Dit is een **demo**, geen productiesite. `noindex,nofollow` staat bewust in elke HTML-pagina en `robots.txt` blokkeert indexering. Pas dit pas aan bij de definitieve livegang.
- Vervang `info@ljstudio.nl` door het echte adres van Joshua.
- Laat Joshua de teksten, diensten, werkgebied, contactgegevens en foto's controleren.
- AI-sfeerbeelden zijn geen echte projectfoto's; vervang ze waar mogelijk.
- Het formulier opent slechts een conceptmail in het e-mailprogramma van de bezoeker; het verzendt niet automatisch. Voor betrouwbare formulieraflevering moet een backend of formulierdienst worden gekoppeld en met een echte test worden gecontroleerd.
- Werk de privacyverklaring bij op basis van definitieve hosting en contactgegevens.
- Stel pas na keuze van een definitief domein de canonical URL's, Open Graph URL's, sitemap.xml, robots.txt en Search Console in.
- Controleer op de definitieve hosting ook HTTPS, www/non-www, 404, telefoon/WhatsApp, mobiel menu, toetsenbord, afbeeldingen, responsive weergave en formulierontvangst.

## Pakket
3 commerciële pagina's: `index.html`, `diensten.html`, `contact.html`. Aanvullend `privacy.html` en `404.html`. Eén assets-map met CSS, JS en beelden. Geen CMS, dashboard of automatisch formulier.
